## 2025-02-18 - RNG State Divergence in Sample Reduction
**Learning:** When optimizing `numpy` random generation by reducing sample count (generating only active samples instead of full buffer), the first output sequence is a prefix of the original. However, subsequent random calls will diverge from the original sequence because the RNG state advances differently (fewer numbers consumed).
**Action:** When performing such optimizations, verify "correctness" by checking that the prefix matches the baseline (using a fixed seed), but acknowledge that downstream random values (e.g. subsequent layers or stereo channels) will change. Document this behavior change as it affects reproducibility of specific random seeds, though the statistical properties (white noise) remain valid.
